日期：2026-10-30。目的：把实验室现有数据资产公开给协作方，说明 shipreid 这一新发现的用途与采样实验设计。

## 2 shipreid 为什么关键

现有跟踪实验的核心短板是**样本量**（12–25 个查询），无法对"核验器能力"做统计推断。shipreid 提供：

1. **硬身份标签**：同 ID = 同一艘船（跨相机、跨时刻），异 ID = 不同船；
2. **规模**：35.8 万训练图，可任意扩大评估样本；
3. **尺度对口**：93×20 px 与跟踪场景中的船舶候选同量级；
4. **任务同构**：判定"两张图是否同一艘船"正是"恢复候选身份核验"的本质问题，只是剥离了跟踪的时序复杂性。

由此可以做一件此前做不到的事：**在干净任务上标定核验器的能力上限**，再回到跟踪场景解释"为什么赢/为什么输"。

## 3 采样与实验设计（本次执行）

### 3.1 采样

- 从 `query` 中取 N=50 个身份（可配对 ID 共 2,942 个）；
- 每个身份构造两对：**同 ID 对**（query 图 + test/train 中同 ID 的另一张）与**异 ID 对**（query 图 + 随机另一身份）；
- 合计 100 对（同 50 / 异 50），随机种子 20261030。

**注意**：同 ID 对是**跨相机/跨时刻**的配对，比跟踪场景中"同视频内的候选"更难——结果应理解为**下界**，需在报告中注明。

### 3.2 预处理

裁图高度 20 px 左右，直接送入视觉编码器会低于最小可处理尺寸，因此按"高度至少 64 px、等比放大、双三次插值"统一预处理；参考与候选使用完全相同的预处理。

### 3.3 对照通道

| 通道 | 做法 | 成本 |
|---|---|---|
| **视觉特征余弦** | Qwen2.5-VL 视觉塔 merged-token 均值特征，余弦相似度，阈值扫描取最优 | 2 次前向/对 |
| **VLM 生成式判断** | 同一模型，输入参考图 + 候选图，要求返回 `{"same": "YES"/"NO", "evidence": "..."}` | 1 次生成/对 |

生成预算：100 次（50 对 × 2）。无效 JSON 单独统计，不补调用。

### 3.4 指标

同 ID 判对率、异 ID 判对率、总准确率；视觉通道另报同/异 ID 的余弦中位数与最优阈值。

## 4 结果用途

| 情形 | 结论 | 对课题的意义 |
|---|---|---|
| VLM 显著优于视觉特征 | 语言核验在"认船"上有真实能力 | 跟踪中未取胜的原因在候选质量与时机构，方法有改进空间 |
| 两者相当 | 语言未提供额外身份信息 | 语言作为可选通道保留，重心转向视觉证据融合与门控 |
| VLM 显著更差 | 该尺度下语言无判别力 | 语言模块收缩有硬证据，开题的否定性结论更扎实 |

无论正负，均以 100 对规模给出可复算的统计，避免此前 12–25 查询的样本量问题。

## 5 边界

- 单数据集、单模型（Qwen2.5-VL-7B）、单次随机采样；扩样（N≥200 对）与重复采样留待下一轮；
- 跨相机同 ID 对的难度高于跟踪场景，不能直接换算为跟踪性能；
- 裁图为人工标注框，不含检测误差，与跟踪候选的生成噪声不同。
